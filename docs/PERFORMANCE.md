## Targets and honest limits
- **Citizen web app on 2G:** a first visit takes about 30 s, because the gzipped bundle is still 923 KB. Repeat visits take under 1 s. Further cuts (route-level code splitting, dropping unused icon fonts) are tracked for Phase 8. Basic-phone users have SMS/IVR (docs/CHANNELS.md), which need no data.
- **Native cold start < 4 s on a low-end phone, and APK size:** these cannot be measured in this environment (no Android build toolchain or device). Measure them with `eas build --profile preview` on a 2–3 GB RAM device and record the numbers here before release. The JS that ships in the APK is the same Hermes bundle as above.
- "First paint" shows "—" because the headless browser did not report a paint entry for these pages. Load time is the reliable figure.
