## D-053 — Free always-on hosting: Oracle Cloud Always Free in an Indian region
Render's free plan sleeps after 15 minutes idle, has no Indian region and loses data without a paid disk. Oracle Cloud's Always Free VM (Mumbai or Hyderabad) never sleeps, keeps its disk and keeps data in India. `deploy/oracle-free.sh` wraps the existing systemd install with Caddy (automatic HTTPS), the firewall ports, swap and a daily encrypted backup. Free tiers carry no SLA: move to a MeitY-empanelled paid region or the State Data Centre before a government go-live.

## D-054 — Real SMS through MSG91; keys added on the server with one command
The generic `dlt-http` driver posted a format no Indian gateway accepts as-is. `SMS_DRIVER=msg91` speaks MSG91's Flow API (DLT template id + numbered variables) and fails closed: a message type with no approved DLT template is not sent. Keys never enter git or chat: `deploy/set-keys.sh` writes them to `/etc/sankalp/sankalp.env` (0600), adds only that provider's host to `EGRESS_ALLOWLIST`, restarts and tests live (Sarvam: a one-line chat call, nothing changed if it fails; MSG91: optional test code to a phone). MSG91 is an Indian company and DLT SMS travels over Indian operators; confirm its data-storage location in the contract before go-live.

## D-055 — Sarvam AI for complaint understanding and photo analysis
Text and photo analysis run on Sarvam's hosted models (Indian company, Indian infrastructure), through the AI gateway and `safeFetch` only.
- Text: `sarvam-105b` on `/v2/chat/completions` with `reasoning_effort: "none"`. With thinking on (the model default), short JSON answers came back empty because the token budget went to reasoning, so every complaint silently fell back to keyword rules. `SARVAM_REASONING` can turn thinking back on.
- Photos: `gemma4` on `/v2` (image input; `/v1` rejects images). It is used for "what does this photo show" and "is it visibly fixed". It stays fail-closed: no answer or an invalid answer means manual review, and the vision signal is one input to the verification engine, never the decision on its own.
- The privacy notice names Sarvam as the AI processor whenever it is enabled (DPDP informed consent). `AI_VISION_PROVIDER=off` keeps photos on manual review only.

## D-056 — SOS voice: 10-second clips to police, deleted 5 days after recording once closed
The phone records 10-second clips (up to six) during a women-safety SOS and sends each to the police the moment it is recorded, from the Android app and now also from the web/iPhone app (browser MediaRecorder).
- Police play the clips from the incident on both command screens through short-lived signed links. Each signing is audited, and no login token ever goes into a URL; the old `?token=` players returned 401 and leaked the token into logs.
- Clips are deleted `retention.sosAudioDays` (default 5) days after recording, but only once the SOS is closed, never while it is open, and never under legal hold. Police can press "Keep as evidence" to place a legal hold. The hourly job logs every deletion, and the privacy notice states the rule.
- Fixed along the way: incidents now carry `sosId`, so clips reach the right incident on the police screens; cancelling an SOS with the PIN marks the police incident safe and frees the patrol van.

## D-057 — Own AI: consented real training data now, self-hosted Patram-7B when a GPU is rented
Training needs real labels, so labels come only from what happened: officer-worked categories for "before" photos, and the citizen's own yes/no for proof photos.
- Use of photos for training is a separate opt-in (off by default, audited, can be withdrawn). The state-admin export uses EXIF-stripped copies only and is audited.
- Patram-7B (BharatGen, Apache-2.0, gated) gets a ready setup for an Indian GPU VM (`deploy/gpu/`): an OpenAI-compatible endpoint behind HTTPS, reachable only from the SANKALP server, with a bearer key. `set-keys.sh patram` switches vision to it after a health check.
- Patram is document-focused, so street-photo classification should come from a model fine-tuned on our own labelled data. A new model goes live only if it beats the current one on a fixed test set (docs/AI_TRAINING.md).
- Until a GPU is rented, Sarvam (Indian) does the AI work.

## D-058 — Open Government Data (data.gov.in): live mandi prices first
data.gov.in is the Government of India's open-data API (free key). The first use is daily mandi prices from Agmarknet for the user's district, falling back to the state, cached for an hour. Only the state and district names are sent.
- The key has to go in the query string, so it is never logged, it is scrubbed from errors, and it never appears in responses.
- data.gov.in answers only from Indian networks, which suits our hosting.
- Without a key the feature reports `not_configured` and the app hides the card.
- `set-keys.sh datagov` tests the key on the server before saving it.
- Full scheme details (eligibility, how to apply) are not on data.gov.in; they need myScheme access through API Setu.

## D-059 — Sankalp Points: earned only for real, verified outcomes
The old rules gave +10 just for filing and +1 for each upvote, which rewards spam. Now:
- Points: +3 when a department accepts a complaint, +10 when the fix is verified, and +5 for answering whether a fix was real (an honest "no" earns the same as "yes"). Smaller points with daily caps: checking a neighbour's repair (+3, up to 5 a day), supporting someone else's complaint (+1, up to 5), reporting an unsafe area (+2, up to 3).
- Nothing for filing, nothing for supporting your own complaint, nothing for SOS. Each outcome is awarded once.
- Every award is a ledger line; people see their history and the rules. Earlier points are kept as one "earlier activity" line, and erasure deletes the ledger.
- Levels run Nagrik → Sankalp Ratna (0/50/150/400/1000/2500). Badges come from ledger counts only.
- The certificate is a signed link anyone can open; it shows the live record with first name and initial only.
- Rewards are recognition until a state or partner sponsors real ones; the app says so rather than showing invented prizes.

## D-060 — Official live alerts from NDMA SACHET; Hindi national news from PIB
- SACHET is NDMA's Common Alerting Protocol system, the same alerts IMD centres, CWC and State Disaster Management Authorities send to phones. We read its all-India feed (read-only) every 10 minutes.
- An alert belongs to a state when its issuer or text names the state, its capital or a district (for example "IMD Chennai" or "Andhra Pradesh SDMA"); it belongs to a district when it names the district. Alerts are shown for 36 hours, with nothing shown if there is no current alert.
- The feed answers only from Indian networks.
- When the app is in Hindi, the India news tab uses PIB's own Hindi national feed (official Hindi releases, not machine translation).

## D-061 — Bills, RTI and budget: real paths only, nothing pretended
- **Bills:** SANKALP is not a payment company and fakes no bills. Outside demo mode the bills screen lists the state's official electricity payment portals and explains Bharat Bill Payment (BBPS) in any UPI app.
  - The portals are in `config/bill-portals.json`: 20 states and UTs, 24 links, each opened from an Indian server and kept only if it answered with the organisation's own page. One guessed domain had become a casino site and was dropped.
  - In-app payment needs a licensed BBPS partner and the owner's KYC.
- **RTI:**
  - New RTIs are drafts.
  - "Submit" no longer marks them "acknowledged" (that was fake). Instead the citizen files on RTI Online or their state portal, then records the official registration number and date, which starts the RTI Act's 30-day clock.
  - First-appeal guidance appears after day 30; the citizen marks when the reply arrives.
- **Budget:** officials (state, or district admin for their own district) publish budget lines that must cite an official https `.gov.in` / `.nic.in` source. Unsourced lines are hidden outside demo mode and count as demo data.
- **Rewards:** a coin animation and toast show only when the points ledger really grew. The leaderboard adds "This month" (ledger points earned this month) and a district filter.
